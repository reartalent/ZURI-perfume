Zuri — Premium Perfume Landing Page

An immersive, high-fidelity front-end landing page built for **Zuri Eau de Parfum**. This project blends luxury branding with dynamic, interactive web design, featuring fluid atmospheric elements and floating 3D-like structural fragments.



Project Media
Submission Video: https://youtu.be/0cQwl_VdGTc
Live Interactive Demo:https://zuri-eau-de-parfum.vercel.app/



 Core Design Features
 Fluid Cloud Animations:** Creates an ethereal, "Wear the sky" atmosphere that shifts seamlessly as the user scrolls.
 Dynamic Elements:** Features layered crystal gems, perfume bottles, and fresh ingredients (bergamot, white peony) that float across the screen to create depth.
 Luxury Visual Identity:** A strict, premium purple and lavender aesthetic designed to mirror modern high-end fragrance campaigns.
 Scent Profile Storytelling:** Interactive text blocks that guide the user through the fragrance notes—from the crisp Bergamot opening to the warm Cashmere Musk and White Amber dry-down.



 Built With
HTML5** — Semantic markup for structure and SEO optimization.
CSS3** — Custom keyframe animations, complex positioning, and glassmorphic UI layers.
javaScript** — For handling fluid interactions and scroll-based motion.
